Governance

Rights are data. Authority is explicit.

The interface is designed around deny-by-default media operations, not around hiding control state behind convenience UI.

01

Provenance first

Source media, physical evidence, rights revisions, derived segments, and vector lineage stay attributable to their origin.

02

Purpose-specific rights

API, MCP, advertising, export, licensing, publication, and provider processing are separate grants rather than one broad permission.

03

Retrieval is not authorization

A high-similarity match can surface evidence. It cannot create publication rights, commercial authority, or provider-promotion authority.

04

Human release control

Infrastructure readiness and successful tests remain evidence inputs. Named capability activation still requires bounded human approval.
