# TMG Video Services

TMG Video Services is a Tolani ecosystem repository for governed video intelligence infrastructure.

> Status: G0 / internal prototype. No public commercial API, MCP service, advertising product, dataset export, or licensing capability is represented as live.

The repository inherits portfolio commercial-context governance from `Tolani-Corp/TolaniCorp-HQ` and is designed around rights-aware, provenance-preserving, deny-by-default media retrieval.
